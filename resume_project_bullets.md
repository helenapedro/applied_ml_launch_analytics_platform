# Resume-Ready Project Bullets: Data Reliability & Predictive Analytics Platform

- Built an end-to-end analytics pipeline in Python that ingests launch data from SpaceX APIs and web sources, standardizes heterogeneous payload/booster attributes, and produces analysis-ready datasets for BI and ML workflows.
- Engineered reusable transformation logic (data typing, schema normalization, feature preparation, and launch/core joins) to improve data quality and enable consistent reporting across launch operations metrics.
- Developed and benchmarked multiple predictive models (Logistic Regression, SVM, Decision Tree, KNN) using cross-validation and hyperparameter tuning, then compared model/test accuracy and confusion matrices to select best-performing approaches.
- Delivered an interactive analytics app with Plotly Dash to support self-service exploration of launch outcomes, payload behavior, and booster reusability patterns through filterable visualizations and model-comparison views.
